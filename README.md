# Legacy Game Tools

古いゲームが現在のAndroidで起動直後にクラッシュする問題を改善する、Vector用の互換モジュールです。

## 対応するゲーム

| ゲーム | 確認した版 | パッケージ |
| --- | --- | --- |
| グルミクD4U（体験版） | 1.2.1 / code 8 | `com.bushiroad.d4djddedition` |
| セカイ（体験版） | 1.0.0 / code 200005 | `com.sega.pjsekai.re` |

arm64版の特定のUnityエンジンに対応します。同じゲーム名でも別のアプリや異なるエンジンの版には適用しません。

## 使い方

1. [GitHub Releases](https://github.com/OneUI-Mods/legacy-game-tools/releases)から署名済みrelease APKをインストールします。
2. root環境のVectorなど、Xposed API 102に対応するフレームワークでモジュールを有効にします。
3. 対象として上記2本を選択します。SystemUIやシステムフレームワークを選ぶ必要はありません。
4. 本アプリで使いたいゲームの互換修正をONにし、ゲームを終了して起動し直します。

既存のゲームAPKや保存データを入れ替える必要はありません。設定はゲームごとに変更でき、次のプロセス起動時に反映されます。端末の再起動は不要です。

## 修正する範囲

古いUnityのメモリ追跡が現在のAndroidのメモリ配置に対応できず、起動直後に落ちる問題を補います。実際のメモリ確保・解放はゲーム本体に任せます。

両体験版のオンラインサービスは終了しています。本アプリはサーバーへの接続やサービスを復旧せず、ゲームデータも配布しません。通信待ちによる停止や、ゲーム全体を遊べることまでは保証しません。

実機ではAndroid 17 / Galaxy S26 Ultraで、グルミクD4Uが通信待ち画面、セカイが起動後の注意書き画面まで進むことを確認しました。Android 12以降へインストールできますが、他のOS・端末での動作は未確認です。

## セカイのBPM定義

0.2.0-rc1では、対象のセカイ体験版で、英数字2桁のBPM IDを読み取る互換修正を追加しています。セカイの互換修正スイッチと連動し、ゲームの次回起動から適用します。BPM値・ノーツの時刻・音声は変更せず、他の正規表現やD4Uには適用しません。実機確認前の候補版で、譜面全体や音声の互換性を保証するものではありません。

## 無効化・削除

本アプリの対象スイッチ、またはVectorのモジュールをOFFにしてゲームを起動し直すと、純正の処理へ戻ります。ゲームのデータ削除は不要です。

## セカイ体験版のライフ

セカイの設定に「ライブ中のライフ減少を防ぐ」を追加しています（初期状態ON）。ミス判定・スコア・コンボ・回復はそのままです。起動互換修正が有効な場合に適用され、切り替え後はゲームを終了して開き直してください。対象は対応する体験版1.0.0のみです。実験版のためライブ完走の実機確認は残っています。実装範囲は[開発者向け資料](docs/sekai-life.md)を参照してください。

## タイトルとライブ開始の待ち時間

「タップでタイトルコールをスキップ」と「ライブ開始の白い遷移を短縮」を個別に切り替えられます（初期状態ON）。読み込み・認証・曲とノーツの同期処理は維持し、タイトルのボイス待ちと白い演出を短縮します。変更後はゲームを終了して開き直してください。実機での操作確認は残っています。[開発者向け資料](docs/sekai-flow.md)に対象と検証範囲を記載しています。

ソロライブでは、音声準備後の遷移フェードが実際に完了した場合に、6秒の固定待機も切り上げます。完了を確認できない場合は従来相当の待機に戻ります。この動作も「ライブ開始の白い遷移を短縮」で切り替わります。
