# セカイ体験版のライフ減少抑制

対象は `com.sega.pjsekai.re` 1.0.0 / versionCode 200005、arm64 の既知の IL2CPP バイナリだけです。管理画面のセカイのカードで切り替えます。初期状態は ON、互換修正全体が OFF の場合は適用しません。変更はゲームプロセスの次回起動時に読みます。

## 実装範囲

`Sekai.Core.Live.ScoreLogic.Damage(INote)` (RVA `0x1686048`) の入口だけをフックします。既知の ELF Build ID と先頭 16 bytes が一致しない場合は適用しません。ABI は `void(this, note, MethodInfo*)` です。

原版の処理を静的解析すると、ノーツ種別と判定に対応するダメージを取得し、ライフから差し引き、0 以上に丸めてビューへ通知しています。スコア計算、判定数、コンボ更新、回復、リザルト処理はこの入口にはありません。ON の場合はこの減算処理を呼ばず、OFF の場合は元の関数へ全引数を転送します。メモリ内のライフ値を定期的に書き換える処理はありません。

`MultiScoreLogic.Damage` の既存ラッパーもこの基底関数を呼びます。オンライン機能や通信プロトコルの変更は追加していません。配信終了した体験版向けの機能であり、現行製品版は対象外です。

## 検証

ホスト試験は ON 中の繰り返し減算抑制、OFF 時の引数を保持した元処理呼び出し、再度 ON にした場合の抑制を確認します。BPM と Unity メモリ管理の既存試験も実行します。実機のライブとリザルト到達は別途確認が必要です。ログの `sekai_life_ready` は入口フックの設置、`sekai_life_loss_prevented` は初回の減算抑制を示します。設置ログだけで動作完了とは扱いません。
