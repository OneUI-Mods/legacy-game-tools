グルミクD4Uとセカイの体験版が、現在のAndroidで起動直後にクラッシュする問題に対応しました。ゲームごとに互換修正を切り替えられます。

対応するのはグルミクD4U 1.2.1とセカイ 1.0.0のarm64版です。rootとXposed API 102に対応するVectorが必要です。Android 17のGalaxy S26 Ultraで起動後の画面表示まで確認しています。他の端末・OSでの動作は未確認の実験版です。

インストール後はVectorで本モジュールと対象ゲーム2本を有効にし、ゲームを終了して開き直してください。端末の再起動やゲームデータの削除は不要です。

体験版のオンラインサービスは終了しています。本アプリは起動互換性を改善するもので、サービス復旧やゲームデータの提供は行いません。通信待ちやゲーム全体の進行は修正対象に含みません。
