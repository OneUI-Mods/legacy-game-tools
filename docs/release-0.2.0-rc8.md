# Legacy Game Tools 0.2.0-rc8

タイトルコールのスキップを有効にした際、起動ロゴの後でクラッシュする問題を修正しました。再生中のタイトル音声だけを停止し、予約中なら次の画面へ進んだ後に再生されないようにします。

白いライブ遷移は、純正のフェードの長さを保ち、白いまま止まる固定待機だけを短縮するように変更しました。ソロライブではフェードと純正の遷移表示の終了を確認した場合に6秒待機を切り上げ、確認できない場合は従来相当の待機へ戻します。

粒子などの遷移演出も純正の終了タイミングを保ちます。タップ補助はゲームがフォーカスを持つ間だけ動作します。

対応するセカイ体験版1.0.0のarm64版専用です。上書き更新後はゲームを終了して開き直してください。端末やSystemUIの再起動は不要です。2機能とも設定から個別に無効化できます。

Android 17の実機で、タイトルコール再生中のタップからライブメニューへ進むことと、純正の遷移演出を保ってライブへ進むことを確認しています。
