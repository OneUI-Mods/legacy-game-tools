# Legacy Game Tools 0.2.0-rc4

タイトルコール中のタップがスキップに反映されない場合に対応し、タッチ開始からも通常のログインへ進めるようにしました。

ソロライブ開始時は、データと音声の準備後、遷移フェードが実際に完了したら6秒の固定待機を切り上げます。完了を確認できない場合は従来相当の待機へ戻ります。音声遅延の計測と曲・ノーツの時刻は維持します。マルチライブやチュートリアルは従来の待機を使います。

対応するセカイ体験版1.0.0のarm64版専用です。上書き更新後、ゲームを終了して開き直してください。端末やSystemUIの再起動は不要です。「ライブ開始の白い遷移を短縮」をOFFにすると完了待ちへの変更も無効になります。

実験版です。実際のタイトル操作とライブ完走の確認は残っています。
